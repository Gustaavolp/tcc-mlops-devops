# 📊 Preprocessing

Este módulo é responsável pela **análise exploratória inicial dos dados** e pela **normalização das informações** para geração de arquivos no formato `parquet`.

> ⚠️ **Importante:**  
> Este código **não faz parte do pipeline de produção**.  
> Ele é utilizado exclusivamente para fins de análise e experimentação.

---

## 🎯 Objetivo

O propósito deste módulo é:

- Realizar análise inicial dos dados
- Aplicar etapas de normalização
- Gerar arquivos `.parquet`
- Preparar datasets para treinamento de modelos
- Testar diferentes hipóteses e estratégias de modelagem

---

## 🚀 Como Executar

Execute o script abaixo:

```bash
python normalization.py
```
